# Homework Bot VK 🤖

Бот для ВКонтакте, который автоматически отслеживает статус проверки домашних работ на платформе Яндекс.Практикум и присылает уведомления об изменениях.

## 🚀 Возможности

- **Автоматическая проверка**: Бот опрашивает API Яндекс.Практикума каждые 10 минут.
- **Уведомления в VK**: Как только ревьюер проверяет работу, вы сразу получаете сообщение с вердиктом.
- **Устойчивость к ошибкам**: Бот не падает при недоступности API или проблемах с сетью.
- **Умное логирование**: Все события записываются в лог (вывод в `stdout`), а критические ошибки дублируются сообщением в VK (с защитой от спама).
- **Безопасность**: Все токены и личные данные хранятся в переменных окружения (`.env`).

## 🛠 Технологии

- Python 3
- `requests` — для работы с API Практикума.
- `vk-api` — для отправки сообщений ВКонтакте.
- `python-dotenv` — для загрузки переменных окружения.
- `pytest`, `flake8` — для тестирования и проверки стиля кода.

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий:**
   git clone https://github.com/ваш_никнейм/homework-bot-vk-new.git
   cd homework-bot-vk-new
2. Создайте и активируйте виртуальное окружение:


python -m venv venv
source venv/Scripts/activate  # Для Windows
# source venv/bin/activate    # Для Mac/Linux

3. Установите зависимости:


pip install -r requirements.txt
Настройте переменные окружения:

4. Создайте в корне проекта файл .env и добавьте в него свои данные:

PRACTICUM_TOKEN=ваш_токен_практикума
VK_TOKEN=ваш_токен_группы_вк
VK_USER_ID=ваш_id_вконтакте

5. Запустите бота:

python homework.py

# Как это работает
При запуске бот проверяет наличие всех необходимых токенов.

Отправляет GET-запрос к API Практикума, передавая метку времени (from_date).

Если в ответе есть новые домашние работы, бот извлекает их статус.

На основе статуса (approved, reviewing, rejected) формируется текст сообщения.

Сообщение отправляется через VK API.

Если возникают ошибки (например, API недоступно), бот логирует их и уведомляет вас в VK (один раз на ошибку, чтобы не спамить).
